Add these optional MP3 files to this folder. The app will play them when the corresponding event happens:

- `call-join.mp3` — another peer joins the room
- `call-leave.mp3` — another peer leaves the room
- `presentation-start.mp3` — a peer starts screen sharing
- `message-arrival.mp3` — a new message arrives while the chat is closed

Missing files are ignored quietly. Short sounds (under one second) work best.
